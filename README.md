# Stone Paper Scissors

## Here's what the project does:

- ✅ The player chooses Rock (1), Paper (2), or Scissors (3) as input.
- ✅ The computer randomly generates its choice using the `rand()` function.
- ✅ The program compares the choices and determines the winner of each round.
- ✅ It keeps track of the number of wins, losses, and draws across all rounds.
- ✅ At the end of the game, it displays a clear summary of results.
- ✅ The console colors change for better user experience:
  - 🟢 Green = Win
  - 🔴 Red = Loss
  - 🟡 Yellow = Draw
